# 下班啦 v1.9 安装包

GitHub 仓库的单文件大小有限制，安装包分为两个标准 ZIP 分卷：

- `下班啦-v1.9-github.z01`
- `下班啦-v1.9-github.zip`

请下载两个文件并放在同一目录，在 macOS 终端执行：

```sh
zip -s 0 下班啦-v1.9-github.zip --out 下班啦-v1.9.zip
```

然后解压生成的 ZIP，首次打开「下班啦.app」时可右键选择「打开」。合并后 ZIP 的 SHA-256：

```text
1e1e3bedc85e95b8641e8e629d3d0cdbba37cb06d3dacd871d05dd335b7a79de
```

# 下班啦 v1.8.6 安装包

GitHub 普通仓库不接受大于 100 MB 的单个文件，因此安装包被拆为两个标准 ZIP 分卷：

- `下班啦-v1.8.6-github.z01`
- `下班啦-v1.8.6-github.zip`

请下载两个文件并放在同一目录。macOS 终端执行：

```sh
zip -s 0 下班啦-v1.8.6-github.zip --out 下班啦-v1.8.6.zip
```

再双击生成的 `下班啦-v1.8.6.zip` 解压并打开「下班啦.app」。

合并后完整安装包的 SHA-256：

```text

```

# 自动计时、到工位缓冲、设置窗口可调高度

## 结果

- 新增弹性模式「自动计时」：每个工作日第一次有效解锁回到桌面时检查一次，满足上班日和时间窗口就自动记上班时间。
- 新增「到工位缓冲」：自动开始或手动点击「开始上班」时回拨 1/3/5/10/15 分钟。
- 设置窗口高度可拖动 500–1000，默认 680。
- 新增 Tests/（无 XCTest，swiftc 编译断言程序）。
- 全部未提交，等真机验收。

## 教训

- 未锁屏时 CGSessionCopyCurrentDictionary 不含 CGSSessionScreenIsLocked 键，不能把「没有键」当成已解锁；自动开始必须有正向解锁证据。
- 手动打开 App 不等于开机登录：用 utmpx 控制台登录时间 + 「登录时打开」+ 5 分钟窗口判断。
- NSHostingView 在窗口显示后会把 contentMinSize/contentMaxSize 清零，尺寸限制要放在 NSWindowDelegate.windowWillResize。
- 「离开满 4 小时」规则被用户否决：产品前提是当天第一次打开 Mac 即上班。

## 教训

- `.ignoresSafeArea()` 必须放在修饰链最外层，否则自绘圆角背景按安全区排版，顶部被裁、红黄绿按钮露在窗外。
- 15.x SDK 编译的窗口在 macOS 26 只有小圆角；大圆角靠透明窗口 + SwiftUI 自绘。
- 预览缩略图里的数字要 `.lineLimit(1).fixedSize()`，窄宽度下会折行。

## 已确认的产品规则

功能说明以 README.md 为准（README 尚未同步本次「关于」功能，待补），这里只记不看会改错的设计决定：

- 提醒只在上班期间触发，不给「仅在上班时」开关。
- 喝水、小彩蛋都只有「提醒间隔」；下班提醒只有开关，当天只播一次 → **已改为按下班时刻去重，见上**，无预览。
- 喝水/彩蛋视频轮回随机：每轮每个播一次，跨轮不连续重复（UserDefaults `reminder.{文件夹}.played/.last`）。
- 设置里叫「主题色」（黑 / 白 / 上传图片），不叫「背景」。图片 80% 不透明 + 30% 黑遮罩，模糊的是卡片后方桌面。
- 已下班态固定绿色，不随主题色变化。桌面小窗左上角只有红、黄两个按钮。
- 「今日工作」= 点阵屏设备面板（TodayPanel.swift）：上方「上班时间」+ 点阵时间成组，下方虚线胶囊「19:00 下班」（时间在前）；右侧胶囊上下键。
- 时间输入：默认选中「时」，改动实时生效无需回车；选中后从第一位重输，第二位拼成两位，只输一位就点别处/切换/按上下键则补零（1 → 01）；到岗时间不能晚于现在。
- 强调色 #D98A68（低饱和陶土橙），用于下班时间、选中段、所有开关开启色、主题色选中圈。用户不喜欢颜色太跳。
- 图片主题两侧亮带是用户背景图自身的浅色立柱，不是 bug。
- 「关于」类弹出面板统一用右上角 ✕ 关闭（不依赖窗口原生标题栏按钮）；用户提过「统一放左上角、和设置窗口一样」但当场决定「先不改」，保持右上角现状——下次若要再加别的弹层，关闭按钮位置以用户最终决定为准，当前默认跟随本次右上角实现。
- `SettingsRow` 包一层 `Button` 做整行可点击时，必须在 `SettingsRow` 内部给 `HStack` 加 `.frame(maxWidth: .infinity)` 并自带 `.contentShape(Rectangle())`，否则 `Spacer` 撑开的空白点击无效（本次踩过的坑，已在 SettingsRow 公共组件里修好，后续行天然继承）。

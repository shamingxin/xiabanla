## 自动计时现行规则（权威版本，代码在 WorkTimerModel.swift）

- 每个工作日（凌晨 5:00 分界）只在**第一次有效回到桌面**时检查一次；检查记录存 UserDefaults `autoStartCheckedDay`，重启 App 不恢复。
- 有效回到桌面 = 有解锁证据 + 屏幕亮 + 会话在控制台、登录完成、未明确锁定：
  - 开机：开了「登录时打开」且 App 在本次控制台登录后 5 分钟内启动（读 utmpx）
  - 唤醒/锁屏后：收到非公开通知 `com.apple.screenIsUnlocked`
  - 只亮锁屏：没有证据，不消耗检查机会
- 检查时自动开始的条件：开关开、弹性模式、今天没上班记录、勾选的上班日（默认一至五）、时间在「凌晨 5:00 ～ 区间结束」。不满足（太晚、非上班日）也算用掉今天的机会，不补触发。
- 自动计时关闭或非弹性模式时解锁，**不占用**当天检查机会；用户已确认维持此行为。
- 到工位缓冲：独立开关，不挂在自动计时下面；开始上班时回拨，记录 = 当前时刻 − 缓冲分钟，不早于凌晨 5:00；自动开始和手动点击「开始上班」均适用，补填不回拨；之后照常走弹性钳制。
- 已移除「离开满 4 小时」规则，启动时清掉旧 key `awayStart`。

## 已确认的产品规则

- 文案：「自动计时」「早晨打开电脑后，自动开始当天的下班倒计时。」「上班日」「到工位缓冲」「开始上班时，将记录的上班时间提前一段到工位的时间。」「缓冲时间」；未开登录时打开时提示「开机后要自动开始，请先开启「登录时打开」。」+「前往通用」。
- 「自动计时」「到工位缓冲」两个卡片都在「通用」分区，不在「工作时长」页。
- 固定模式不显示自动计时卡片；到工位缓冲卡片不受工时模式影响，始终显示。
- 提醒只在上班期间触发；只有喝水有「强制提醒」；下班提醒只有开关，按下班时刻去重。
- 「深浅模式」管浅/深，「主题色」管强调色；已下班态固定绿色。上传图片背景已下线。
- 倒计时样式有「翻页 / 灵动岛 / 待机时钟」三种。待机时钟只影响主卡片，用固定宽度的时分秒三组双色数字：十位深蓝、个位浅蓝，每位按其位置取得稳定但不一致的倾角，并以负间距交叠；所有数字共用同一视觉上下基线，不能波浪式上下错位；秒组每秒独立，新值从下向上接位、旧值向上淡出，再短促压缩/上弹后受控回位，静止时不保留同字阴影，切换样式不改变卡片宽度。系统减少动态效果开启时即时替换。
- 2026-11-10 曾试行“旧值上滑、新值滑入”的待机时钟动画优化，但固定槽位裁切了数字左右边缘，用户已要求完整撤回；现有动画保留，除非用户另行明确提出新方向。

# 提醒卡标题与动画提醒文案

## 目标

将设置中的「提醒」页明确分为喝水提醒、放松提醒和下班提醒三张卡片，并让每张卡片都能配置其提醒动画。

## 已确认的界面

- 三张卡片首行保留为卡片标题与总开关，依次为「喝水提醒」「放松提醒」「下班提醒」。
- 原「随机彩蛋」标题改为「放松提醒」。其现有的提醒间隔和动画选择能力不变。
- 喝水、放松、下班三张卡片的动画设置行统一显示为「动画提醒」。
- 每一行均显示当前已选动画数量，以及「选择动画」「预览动画」两个操作按钮。
- 下班提醒新增动画选择区，沿用提醒模型中下班动画目录，并将选择结果持久化；随机播放与预览仅从已选动画取用。

## 数据与交互

- 下班动画选择采用与喝水、放松相同的默认全选、至少保留一个、离页收起和提示 toast 规则。
- 不改变已有的提醒计时、强制喝水提醒、下班时刻去重或动画弹出逻辑。
- 既有用户没有保存下班选择时，默认选中所有内置下班动画，保证升级后行为连续。

## 验证

- 增加纯 Swift 选择逻辑测试：下班动画默认全选、选择持久化、最后一项不可取消，以及预览/随机候选只来自已选项。
- 构建应用并运行现有测试；检查三张提醒卡片都有标题与「动画提醒」操作行。

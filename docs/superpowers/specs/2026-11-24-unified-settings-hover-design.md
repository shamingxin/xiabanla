# 设置面板统一悬停反馈设计

## 目标

让设置窗口中每个可操作项在鼠标悬停时都显示清晰、一致且不拦截点击的反馈；计时、提醒、导航、持久化和原生菜单行为保持不变。

## 根因

当前实现把悬停视觉分散在 SwiftUI 修饰器和透明 AppKit 控件自身：前者的材质强度不足以从深色玻璃卡片中分辨，后者在透明控件上直接绘制层背景，不能可靠地成为可见表面。两套状态并未共享同一可见的外层。

## 设计

- 新增一个统一的交互表面，由 `SettingsPalette` 提供深浅模式各自的悬停填充和描边。
- SwiftUI 按钮、开关、日期/下拉选择器、工作日和外观/样式选项均使用该表面；表面叠在内容上方，并禁用命中测试。
- 原生 `NSPopUpButton` 与 `NSDatePicker` 只负责鼠标、键盘和原生菜单/步进，不再自行承担悬停绘制；它们通过回调更新 SwiftUI 外层状态。
- 悬停保持矩形或现有控件形状的圆角；按下态仍以既有控件样式为准。

## 验收

- 深色和浅色模式下，任一可操作项悬停时均有可见填充和 1pt 描边。
- 下拉与时间控件仍可点击、弹出原生菜单或使用步进箭头；悬停层不接收点击。
- `Tests/run.sh`、`./build.sh`、`codesign --verify --deep --strict build/下班啦.app` 与 `git diff --check` 均通过。

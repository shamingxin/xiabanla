# 中性玻璃材质设计

## 目标

在不改变任何计时、提醒、导航或持久化逻辑的前提下，将设置窗口和倒计时卡片统一为克制的「macOS 设置面板 + iOS 材质」视觉语言。

## 视觉决策

- 浅色采用暖灰白而非纯白；深色采用带极弱蓝调的深石墨，而非纯黑。
- 窗口保留 `NSVisualEffectView` 的背景模糊。侧边栏为最透的一层，内容区较实，卡片只加很淡的高光层。
- 玻璃边缘使用低透明度白色描边；投影只表达面板层级，不制造厚重悬浮感。
- 设置窗口交互状态固定使用系统蓝。用户原有主题色数据保持不变，但不再影响本次涉及的设置窗口视觉。
- 倒计时卡片沿用同一中性深浅基底；数字仍是主角，超时状态继续使用现有绿色。

## 参数

| Token | 浅色 | 深色 |
| --- | --- | --- |
| window tint | 暖灰白，约 86% | 深石墨，约 82% |
| sidebar tint | 暖灰白，约 48% | 深石墨，约 42% |
| card fill | 白色 52% | 白色 7% |
| stroke | 白色 58% | 白色 14% |
| divider | 黑色 8% | 白色 10% |
| interaction | 固定系统蓝 | 固定系统蓝 |

## 范围和验收

- 仅修改 `SettingsView.swift`、`WidgetContainer.swift`、`CountdownCardView.swift` 及静态展示回归测试。
- 保持现有窗口尺寸、圆角、导航、开关语义、倒计时样式和用户数据行为。
- 移除设置页内可见的主题色选择，避免视觉上出现多种用户强调色；不删除底层保存的主题色数据。
- 通过 `Tests/run.sh`、`./build.sh`、`codesign --verify --deep --strict build/下班啦.app` 和 `git diff --check`。

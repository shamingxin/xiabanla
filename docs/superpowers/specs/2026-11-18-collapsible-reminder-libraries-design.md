# 提醒动画库默认收起设计

## 目标

减少“提醒动画”页的初始高度：喝水提醒和随机彩蛋的动画缩略图库默认收起，需要选择素材时再展开。

## 交互

- 进入“提醒动画”页时，两个动画库都处于收起状态。
- 收起状态只保留标题“播放动画”和已选数量。
- 右侧始终并排显示 22pt 高的“选择动画”和“预览动画”按钮。
- 点击“选择动画”只展开对应库的缩略图网格，并将该按钮改为“收起”。
- 点击“收起”只折叠对应库。两个库的状态相互独立。
- 切换到任何其他设置分区时，两个库的展开状态立即清空；切回“提醒动画”页后仍均为收起。

## 状态与边界

- 展开状态是 `SettingsView` 的瞬态 `@State`，不写入 `UserDefaults`，不跨窗口、重启或分区切换保留。
- 视频选择、预览、随机池过滤和“至少保留一个动画”的现有逻辑保持不变。
- 某类动画没有可用视频时，预览和选择按钮禁用；仅在该库展开时显示“未找到内置动画。”提示。

## 验证

- 将“提醒动画”页的展开状态提取为无 UI 依赖的纯状态值，测试默认收起、单库切换、独立性和离开页面复位。
- 运行完整 `./Tests/run.sh` 和 `./build.sh`。

# 默认开机自动倒计时设计

## 目标

让所有用户（包括已经安装旧版本的用户）在升级后的下一次启动时，默认获得“登录时打开”和“自动计时”两项能力；自动计时按设置页的“上班日”选择执行，初始选择为周一至周五。

## 行为

- 一次性迁移会把 `launchAtLogin` 和 `autoStartEnabled` 设为 `true`，并向 macOS 注册主 App 登录项。
- `autoStartWeekdays` 若尚未保存，使用现有默认值周一至周五。
- 迁移完成后记录独立版本标记；之后不再覆盖用户在设置页中关闭开关或修改上班日的选择。
- 自动倒计时仍沿用现有安全条件：仅弹性模式、选中的上班日、凌晨 5:00 至上班区间结束、当天尚未开始；App 必须在登录后 5 分钟内由登录项启动，或在之后收到有效解锁通知。

## 实现边界

- 迁移逻辑放在 `WorkTimerModel` 初始化阶段，确保首次运行和升级后都在界面建立前完成。
- 初始启用登录项需直接调用既有 `LoginItemManager`，因为属性初始化不会触发 `didSet`。
- 不改变设置页布局、开关文案、星期选择控件或既有自动计时判定规则。
- 不处理 Developer ID 签名或公证；它是独立的发布链路问题。

## 测试

- 新用户/未迁移用户：迁移后两个开关为开启状态，星期默认周一至周五，迁移标记已写入。
- 已迁移且用户手动关闭：后续初始化保留关闭状态，不重新开启。
- 现有自动计时判定、工作日选择和登录窗口测试持续通过。

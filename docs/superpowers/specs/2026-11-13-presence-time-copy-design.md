# 在岗时间文案：设计规格

## 目标

将原「屏幕时间」分区改为「在岗时间」，明确其统计的是公司电脑上的实际在岗片段，而不是 macOS 或其他 App 的屏幕使用时间。

## 术语

- **在岗时间**：提前到公司开电脑、正常工作、下班后加班的实际在岗片段总和；睡眠、熄屏、关机之间的离线间隔不计入。
- **计划工作时长**：设置页“工作时长”中的每日规则，继续保留原名，不与在岗时间混用。

## 文案映射

- 侧边栏与页面标题：`屏幕时间` → `在岗时间`
- `本周累计工作时长` → `本周累计在岗时间`
- `每天的工作时长` → `每天的在岗时间`
- `当天累计` / `本周平均` → `当天在岗` / `本周平均在岗`
- 日期标题中的 `工作时长` → `在岗时间`
- 图表辅助功能标签：`本周每天在岗时间`
- 幸福指数跳转：`查看本周记录` → `查看本周在岗`

## 约束

- 不改动数据模型、统计规则、设置中的计划工作时长，或任何自动计时行为。
- README 与接力文档同步澄清“在岗时间”不是系统屏幕时间。

# 下班啦（xiabanla）

macOS 菜单栏下班倒计时 App：菜单栏显示剩余时间，点开是翻页时钟浮层，另有可拖动的桌面小窗；上班期间弹出漫画思考泡动画提醒喝水、放松，下班那一刻播放下班动画。

## 功能

- **工时模式**：弹性 / 固定，默认弹性（上班区间 10:00–12:00，工作 9 小时）
  - 固定：下班 = 上班时间 + 时长，晚到不顺延；未填到岗也直接倒计时
  - 弹性：下班 = clamp(到岗, 区间开始, 区间结束) + 时长；未填到岗显示「未开始」
- **自动计时**（仅弹性模式）：首次安装或升级后默认开启，并默认开启「登录时打开」；每个工作日第一次真正解锁回到桌面时检查一次，满足条件就自动记录上班时间。之后可在设置中关闭或修改上班日
  - 条件：勾选的上班日（默认周一至周五）、时间在「凌晨 5:00 ～ 区间结束」内、今天还没有上班记录
  - 有效回到桌面：开机时需开启「登录时打开」且 App 在登录后 5 分钟内启动；睡眠/锁屏后需收到解锁通知；只亮锁屏不算
  - 第一次检查没开始（太晚、非上班日），当天不再补触发，需手动开始；检查记录持久化，凌晨 5:00 重置
  - 到工位缓冲（默认关闭，1/3/5/10/15 分钟，默认 5）：开始上班时把上班时间往前回拨；自动开始和手动点击「开始上班」均适用，补填不回拨
- **已下班**：菜单栏「已下班，公司倒欠你 H:MM」，卡片绿色正向计时 + 冲击动效进度条；熄屏 / 睡眠 / App 未运行不计；凌晨 5:00 为工作日分界，自动清零
- **提醒**（只在上班期间触发）
  - 喝水提醒：间隔 5 分钟 – 2 小时；「强制提醒」默认开启，动画持续显示至手动关闭，下次从关闭时开始计时。开启喝水提醒和强制提醒后，可设置每日饮水目标（默认 1800 ml）与单次饮水量（默认 200 ml）；点击「我喝啦」会累计水量，另可在在岗时间页快捷补记。饮水统计按凌晨 5:00 切换工作日
  - 休息提醒：和喝水一样，上班期间每隔 N 分钟放一个（5 分钟 – 2 小时）
  - 下班提醒：倒计时结束那一刻播放一次，当天只播一次；可独立选择与预览下班动画
  - 喝水、放松与下班提醒均提供内置动画缩略图库：默认全选，用户可勾选进入随机播放池；每类至少保留一个，最后一项再次点击会提示「至少保留一个动画。」
- **外观**
  - 深浅模式：浅色 / 深色，卡片和设置面板一起切换
  - 设置面板：中性灰白 / 深石墨玻璃材质；所有选中与操作控件统一使用系统蓝，避免主题色干扰界面
  - 倒计时样式：翻页 / 灵动岛 / 待机时钟，只影响主卡片，不影响「今日工作」面板；待机时钟以半透明的深蓝十位、浅蓝个位超大圆体数字构图，带轻微倾角与交叠，秒级更新时短促回弹
- **在岗时间**：默认按天查看。这台公司电脑上从实际到岗（包括提前到公司）到离开电脑的在岗片段会累计，包含正常工作与下班后加班；睡眠、熄屏、关机间隔不计入。开启饮水量统计时，日视图显示当天水杯进度和快捷补记；周视图显示本周累计、日均与轻量文案，不提供补记。数据存于本机 Application Support 的 SQLite 数据库，不读取系统或其他 App 的屏幕使用时间。
- **幸福指数**：根据本周已封存的实际在岗记录生成测试卡。分数只反映计划工时之外的在岗时间；结果以视频封面、手绘星级、分数、称号、统计和短评呈现；首屏按钮为「回望本周」，重新测量只更换短评，不修改任何工时数据。
- **设置面板**：参考 macOS 系统设置，侧边栏分「工作时长 / 提醒 / 通用 / 在岗时间 / 幸福指数 / 外观 / 关于」七个分区，窗口带背景模糊；宽度固定，高度可上下拖动（500–1000，默认 680，记住上次高度）。「提醒」页在右上角以原生风格分段 Tab 切换「喝水 / 休息 / 下班」，各自展示对应设置；可点击控件提供中性的玻璃悬停反馈。

## 视频素材

放在 `Assets/Videos/{喝水,彩蛋,下班}/`，要求 **640×640 正方形 mp4**（非正方形会被裁边），重新打包后生效，使用者不能自行上传。

## 构建与发版

只需要 Command Line Tools：

```sh
./build.sh          # 编译打包到 build/下班啦.app（arm64、macOS 13+、ad-hoc 签名；旧版运行中会先正常退出、完成后自动启动新版）
./Tests/run.sh      # 自动计时、活动数据与提醒浮层布局测试（真实锁屏/解锁仍需真机验证）
mkdir -p release && ditto -c -k --sequesterRsrc --keepParent build/下班啦.app release/下班啦-v1.9.zip
```

`release/` 用于本地安装包，默认被 git 忽略；只有用户明确要求发布包随仓库发布时，才强制暂存指定包。清理旧包须在用户确认后进行。

发版：改代码 / 加视频 → 改 build.sh 版本号 → `build.sh` → 压 zip 到 `release/` → 提交推送 main 并打 tag → 视可用凭据创建 GitHub Release。普通仓库文件超过 100 MB 时，发布低于限制的分卷与合并说明。对方首次打开需右键「打开」。

# 下班啦（xiabanla）

macOS 菜单栏下班倒计时 App：菜单栏显示剩余时间，点开是翻页时钟浮层，另有可拖动的桌面小窗；上班期间弹出漫画思考泡动画提醒喝水、放随机彩蛋，下班那一刻播放下班动画。

## 功能

- **工时模式**：弹性 / 固定，默认弹性（上班区间 10:00–12:00，工作 9 小时）
  - 固定：下班 = 上班时间 + 时长，晚到不顺延；未填到岗也直接倒计时
  - 弹性：下班 = clamp(到岗, 区间开始, 区间结束) + 时长；未填到岗显示「未开始」
- **自动计时**（仅弹性模式，默认关闭）：每个工作日第一次真正解锁回到桌面时检查一次，满足条件就自动记录上班时间
  - 条件：勾选的上班日（默认周一至周五）、时间在「凌晨 5:00 ～ 区间结束」内、今天还没有上班记录
  - 有效回到桌面：开机时需开启「登录时打开」且 App 在登录后 5 分钟内启动；睡眠/锁屏后需收到解锁通知；只亮锁屏不算
  - 第一次检查没开始（太晚、非上班日），当天不再补触发，需手动开始；检查记录持久化，凌晨 5:00 重置
  - 到工位缓冲（默认关闭，1/3/5/10/15 分钟，默认 5）：开始上班时把上班时间往前回拨；自动开始和手动点击「开始上班」均适用，补填不回拨
- **已下班**：菜单栏「已下班，公司倒欠你 H:MM」，卡片绿色正向计时 + 冲击动效进度条；熄屏 / 睡眠 / App 未运行不计；凌晨 5:00 为工作日分界，自动清零
- **提醒**（只在上班期间触发）
  - 喝水提醒：间隔 5 分钟 – 2 小时；「强制提醒」默认开启，动画循环播放，使用「我喝啦」或「还不渴」回应后关闭，下次从回应时开始计时
  - 随机彩蛋：和喝水一样，上班期间每隔 N 分钟放一个（5 分钟 – 2 小时）
  - 下班提醒：只有开关，倒计时结束那一刻播放一次，当天只播一次
- **外观**
  - 深浅模式：浅色 / 深色，卡片和设置面板一起切换
  - 主题色：开关、数字、选中态的强调色；5 个预设（荧光绿、莱茵蓝、黄、粉、红，默认黄）+ 自定义十六进制
  - 倒计时样式：翻页 / 灵动岛 / 待机时钟，只影响主卡片，不影响「今日工作」面板；待机时钟以半透明的深蓝十位、浅蓝个位超大圆体数字构图，带轻微倾角与交叠，秒级更新时短促回弹
- **在岗时间**：默认按周查看。这台公司电脑上从实际到岗（包括提前到公司）到离开电脑的在岗片段会累计，包含正常工作与下班后加班；睡眠、熄屏、关机间隔不计入。数据存于本机 Application Support 的 SQLite 数据库，不读取系统或其他 App 的屏幕使用时间。
- **设置面板**：参考 macOS 系统设置，侧边栏分「工作时长 / 在岗时间 / 幸福指数 / 提醒动画 / 通用 / 外观 / 关于」七个分区，窗口带背景模糊；宽度固定，高度可上下拖动（500–1000，默认 680，记住上次高度）

## 视频素材

放在 `Assets/Videos/{喝水,彩蛋,下班}/`，要求 **640×640 正方形 mp4**（非正方形会被裁边），重新打包后生效，使用者不能自行上传。

## 构建与发版

只需要 Command Line Tools：

```sh
./build.sh          # 编译打包到 build/下班啦.app（arm64、macOS 13+、ad-hoc 签名）
./Tests/run.sh      # 自动计时、活动数据与提醒浮层布局测试（真实锁屏/解锁仍需真机验证）
mkdir -p release && ditto -c -k --sequesterRsrc --keepParent build/下班啦.app release/下班啦-v1.8.zip
```

`release/` 用于本地安装包，默认被 git 忽略、不进仓库；发版前只保留最新版本，清理旧包须在用户确认后进行。

发版：改代码 / 加视频 → 改 build.sh 版本号 → `build.sh` → 压 zip 到 `release/` → 提交推送 main → GitHub 新建 Release 上传 zip。对方首次打开需右键「打开」。
